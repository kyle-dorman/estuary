    A guide to the dataset

    This map is a discovery interface for the 66 study estuaries, not a replacement for the authoritative archival record on Zenodo. It represents dataset version 1.0.0. Markers show locations, not current mouth conditions.

    Locations & provenance

    Locations and names come from the release’s sites.geojson, generated by the repository’s public-data export. Coordinates are estuary mouth points in WGS 84 (EPSG:4326), stored as longitude, latitude in decimal degrees. Site IDs are preserved.
